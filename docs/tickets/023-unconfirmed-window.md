# 023: FR-46: лимит действий без подтверждения
Статус: TODO
Зависит от: 016
Требования: FR-46

## Цель
Если админ ослабил подтверждения, число действий, увеличивающих риск и выполненных без подтверждения, ограничено скользящим окном; сверх — требуется подтверждение.

## Scope
- `executed_actions` и слот, вставляемый в транзакции решения политики под `lock_user` (D-17), не возвращается при отказе биржи.
- Дефолты PLAN раздел 6; снижающие риск и подтверждённые не считаются.

## Non-scope
- Лимит экспозиции (non-goal).

## Acceptance criteria
- [ ] Unit (edge case): серия мелких ордеров без подтверждения превышает окно → следующий требует подтверждения.
- [ ] Integration: два конкурентных клиента на границе окна → проходит ровно лимит.
- [ ] Unit: отмены и закрытия не ограничены.
