Вопрос пользователю (влияет на тикет 007, не на этот спайк): у demo-ключа есть права вне allowlist D-24, поэтому ключ отклоняется. Семантика каждого права — по [Get API Key Information](https://bybit-exchange.github.io/docs/v5/user/apikey-info): `Wallet.AccountTransfer` — переводы между счетами; `Wallet.SubMemberTransferList` — переводы субаккаунта (группа Wallet, не read-only); `Options.OptionsTrade` — торговля опционами и USDC-перпетуалами; `Derivatives.DerivativesTrade` — право торговли, в документации без описания; `Exchange.ExchangeHistory` — Convert (обмен), не история. Варианты (подробно — PLAN «Спайк 004»):
- (а) основной: пересоздать demo-ключ только с Contract Order/Position + Spot Trade и проверить командой `uv run python spikes/004/bybit_demo_probe.py --verify-key ~/.config/guarded-exchange/bybit-demo.env`.
- (б) запасной, только с правкой FR-49: `admin_attested` для demo при праве переводов. Тезис «переводы на demo двигают только демо-средства» — непроверенное предположение.
- Открытый вопрос: нужен ли `DerivativesTrade` для linear на UTA. Если да, его добавление в allowlist D-24 решает пользователь (право торговли, не переводов).
