# 031: Эксперимент с описаниями инструментов (AC-6)
Статус: DEFERRED (v2, решение пользователя 2026-10-29, MVP)
Зависит от: 030
Требования: FR-40, AC-6

## Цель
Сравнить два варианта описаний инструментов и показать изменение метрик в отчёте.

## Scope
- Описания вынесены в `descriptions/*.yaml` (версии v1/v2); раннер принимает версию.
- Ручной прогон обоих вариантов, отчёт с таблицей и выводом — в `docs/` и черновик для README.

## Non-scope
- Fine-tuning, LLM-judge.

## Acceptance criteria
- [ ] Отчёт содержит метрики обеих версий, число прогонов, стоимость (< $0.50 на полный прогон).
- [ ] CI проверяет, что обе версии описаний валидны и покрывают все инструменты.

## Заметки
Требует ключей LLM у пользователя для реального прогона.
